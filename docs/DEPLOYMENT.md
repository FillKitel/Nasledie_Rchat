# Интернет-пилот Маяка v0.9

## Что оплачивать не нужно

Для небольшого закрытого теста: один **Render Web Service Free** и **Neon Free**.
Условия проверены 15 сентября 2026 года:

- [Render Free](https://render.com/docs/free): процесс засыпает после 15 минут
  без входящего трафика, пробуждение может занять около минуты. Локальные файлы
  теряются при перезапуске/публикации. Бесплатный Render PostgreSQL истекает через
  30 дней, поэтому здесь он **не используется**.
- [Neon Free](https://neon.com/pricing): 0,5 ГБ хранилища на проект,
  100 CU-часов на проект в месяц, 5 ГБ исходящего трафика. Следите за квотами
  в панели Neon. Лимиты могут измениться; не включайте платное обновление.

Бесплатный тариф не обещает постоянную доступность или пригодность для большой
аудитории. Не используйте искусственные пинги для обхода сна Render.

## Развёртывание

1. В Neon создайте или используйте отдельный пустой проект Free. Откройте
   **Connect / Connection string**, включите pooling. Скопируйте PostgreSQL URI
   (`postgresql://...`) в секретную переменную Render, не в Git и не в чат.
   Выбирайте регион сервера близко к базе. Для существующего проекта в Ohio
   в шаблоне выбран `ohio`.
2. В Render выберите **New → Web Service → Public Git Repository** и репозиторий
   `https://github.com/FillKitel/Nasledie_Rchat`.
   **Важно:** пока v0.9 находится в `codex/local-realtime-chat`, выбирайте именно
   эту ветку. `main` может содержать старую версию. После согласованного merge
   можно переключить развёртывание на `main`.
3. Runtime **Node**, instance **Free**, build:
   `npx --yes pnpm@11.19.0 install --frozen-lockfile --prod`, start:
   `node --no-warnings=ExperimentalWarning server/index.js`.
4. Добавьте переменные:

   | Имя | Значение |
   | --- | --- |
   | `NODE_VERSION` | `24.19.0` |
   | `NODE_ENV` | `production` |
   | `MAYAK_MODE` | `cloud` |
   | `TRUST_PROXY` | `1` (только за доверенным прокси Render) |
   | `DATABASE_URL` | секретная строка Neon, с TLS |
   | `REGISTRATION_CODE` | случайный секрет не короче 16 символов |

   Используйте генератор секрета Render. Код нужен только при регистрации,
   передавайте его участникам приватно. Для генерации на своём компьютере:
   `node -e "console.log(require('node:crypto').randomBytes(24).toString('base64url'))"`.
   Не используйте пароль Neon как код приглашения.

   `PORT` и `RENDER_EXTERNAL_HOSTNAME` задаёт Render. `PUBLIC_URL` не нужен:
   сервер выводит HTTPS-адрес из `RENDER_EXTERNAL_HOSTNAME`. На другом хостинге
   задайте `PUBLIC_URL=https://ваш-домен` без пути и параметров.
5. Health check `/api/health`. Автопубликацию отключите, проверяйте CI перед
   ручным Deploy. Альтернатива ручной форме — Blueprint из `render.yaml`.
6. После успешной сборки откройте HTTPS-адрес. Health должен показать
   `version: "0.9"`, `mode: "cloud"`, `database: "postgres"`, `inviteRequired: true`.
   Без базы, HTTPS-адреса и достаточно длинного кода cloud-сервер не запустится.
7. Зарегистрируйтесь с кодом; со второго устройства войдите в тот же аккаунт
   или создайте отдельный. Проверьте доставку, личный диалог, удаление и очистку.
   После перезапуска Render аккаунты и сообщения должны сохраниться.

HTTPS работает без покупки домена на поддомене Render. Работа без VPN и при
ограничениях конкретного провайдера не гарантируется: проверьте разные сети.
Это интернет-сервер, не обход белых списков и не mesh-сеть.

## Данные, резервные копии, перенос с Mac

По умолчанию облачный пилот пустой. Старая база на Mac не загружается и не удаляется.
Локальный запуск остаётся прежним без `DATABASE_URL`. Перед первой миграцией старой
SQLite v0.8 сервер автоматически сохраняет рядом файл `.pre-v09-*.bak`.
Это страховка обновления, **не регулярное резервное копирование**.

Снимок всех аккаунтов, профилей, чатов и сообщений:

```sh
# Локальная база (или заданные MAYAK_DATA_DIR / MAYAK_DB_PATH)
node --no-warnings=ExperimentalWarning server/backup.js export backups/mayak.json
```

Для PostgreSQL сначала задайте `DATABASE_URL` приватно в окружении терминала.
Команда экспорта та же. Не вставляйте секрет прямо в команду с сохранением в history.
Файл создаётся с правами `600`, существующий файл не перезаписывается. Для каждого
снимка выбирайте новое имя. Храните резервную копию вне сервиса Render, защищённо.
Файл содержит сообщения и хеши паролей; папка `backups/` исключена из Git.

Восстановление **только в пустую целевую базу** (после настройки её окружения):

```sh
node --no-warnings=ExperimentalWarning server/backup.js import backups/mayak.json --into-empty-database
```

Остановите целевой сервер на время восстановления. При непустой базе утилита
откажется продолжать. Перенос атомарный; при ошибке изменения откатываются.
Сессии устройств не экспортируются — после переноса войдите заново.
Не переносите реальные локальные переписки в облако без согласованного решения.

## Ограничения защиты

- Пароли хешируются scrypt, сессии — HttpOnly/SameSite/Secure cookies в облаке.
- TLS до PostgreSQL проверяет сертификат. Пул ограничен тремя соединениями.
- Есть ограничения запросов, регистраций и входов. Они хранятся в памяти и
  сбрасываются при рестарте; это не полноценная защита от распределённых атак.
- Пилот рассчитан на один серверный процесс: realtime-события не распределяются
  между репликами. Не включайте горизонтальное масштабирование без общей шины.
- Сквозного шифрования и независимого аудита нет. Администраторы приложения и
  БД имеют технический доступ к содержимому. Не обещайте участникам обратное.
- Восстановления пароля, административной панели, вложений и push пока нет.
  Не используйте единственный экземпляр тестовой базы для важных переписок.

# RChat Flutter client

Единый клиент для iOS, Android, macOS и web. На первом этапе он работает с
демонстрационными данными и служит нативной визуальной основой продукта.

## Уже реализовано

- адаптивный layout: mobile, tablet и desktop;
- список, поиск и фильтрация диалогов;
- личные и групповые чаты;
- отправка локальных сообщений;
- профиль собеседника на широком экране;
- светлая и тёмная темы;
- раздельные модели, данные, контроллер и UI-виджеты.

## Запуск

```sh
flutter pub get
flutter run -d macos
```

Платформенные каталоги генерируются командой `flutter create` после первоначальной
настройки SDK.

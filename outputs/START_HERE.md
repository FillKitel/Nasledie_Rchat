# Маяк — первая версия

Первая интерактивная версия находится в папке `app`.

Чтобы открыть её на Mac в живом режиме:

1. Откройте Terminal в папке проекта.
2. Выполните:

   ```sh
   ./script/run_local_chat.sh
   ```

3. Откройте в браузере адрес `http://127.0.0.1:4173`.

Можно выбирать диалоги, искать, отправлять сообщения, получать демонстрационные
ответы и переключать светлую/тёмную тему. На узком экране интерфейс автоматически
переходит в мобильный режим.

В версии v0.3 появился диалог «Живой чат»: откройте тот же адрес во втором окне,
и сообщения будут проходить через локальный сервер без перезагрузки страницы.

В версии v0.4 появилась карточка «Подключить телефон»: наведите камеру iPhone на
QR-код, откройте ссылку в Safari и при желании добавьте «Маяк» на экран Домой.
Телефон и Mac должны быть в одной Wi‑Fi сети.

Название «Маяк», цвета и демонстрационные собеседники пока временные — их можно
заменить, когда определимся с характером продукта.

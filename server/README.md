# Mayak local realtime server

Локальный сервер v0.8 для аккаунтов и живого обмена сообщениями. Требуется
Node.js 22+ со встроенным модулем SQLite. По умолчанию скрипт запуска использует
`node` из `PATH`; свой путь можно задать через `NODE_BIN` в локальном `.env.local`
(пример — `.env.example`). Настройки конкретного компьютера не попадают в Git.

## Запуск

```sh
./script/run_local_chat.sh
```

Откройте `http://127.0.0.1:4173` в двух окнах и используйте диалог «Живой чат».
Для телефона откройте диалог «Живой чат» и нажмите «Локальная комната»: окно
покажет LAN-ссылку и QR-код для iPhone/Android в той же Wi‑Fi сети.
На первом устройстве зарегистрируйте аккаунт: имя, username, пароль и название
устройства. На втором устройстве выберите «Вход» и введите тот же username и
пароль. Пароль хранится только как `scrypt`-хеш, а каждое устройство получает
отдельную сессию.
В окне «Локальная комната» отображаются устройства онлайн, подключённые к этому
локальному серверу. У чужого устройства можно нажать «Написать» и открыть личный
локальный чат: он использует тот же сервер, но отдельный `chatId`.

## API

- `GET /api/health` — версия и счётчики сервера;
- `POST /api/auth/register` — регистрация аккаунта;
- `POST /api/auth/login` — вход и новая сессия устройства;
- `GET /api/auth/me` — текущий аккаунт и сессия;
- `PATCH /api/auth/me` — изменение имени, описания профиля и названия устройства;
- `PUT /api/auth/avatar` — загрузка аватара JPEG, PNG или WebP до 512 КБ;
- `DELETE /api/auth/avatar` — удаление своего аватара;
- `GET /api/users/:id/avatar` — получение аватара авторизованным пользователем;
- `POST /api/auth/logout` — завершение текущей сессии;
- `GET /api/users?query=...` — поиск зарегистрированных пользователей;
- `GET /api/conversations` — список доступных диалогов;
- `POST /api/conversations/direct` — личный диалог с пользователем;
- `GET /api/connect` — LAN-ссылка для телефона;
- `GET /api/connect.svg` — QR-код подключения;
- `GET /api/messages?chatId=live` — история общей локальной комнаты;
- `GET /api/messages?chatId=dm-...` — история личного локального чата;
- `DELETE /api/messages/:id` — удаление своего сообщения у всех участников;
- `DELETE /api/conversations/:id/messages` — очистка истории только для текущего аккаунта;
- `GET /api/presence` — список устройств онлайн;
- `POST /api/messages` — отправка от имени авторизованного аккаунта;
- `GET /api/events` — поток событий для сообщений и участников онлайн.

Аккаунты, сессии, участники и история хранятся локально в
`server/.data/mayak.sqlite` и не попадают в Git. Старый `messages.json` читается
один раз для переноса истории общей комнаты v0.7.

## Проверка

```sh
node --no-warnings=ExperimentalWarning --test server/auth.test.js
```

Тест использует временную базу и проверяет регистрацию, запрет анонимного чтения,
защиту имени автора, доступ к личному чату, удаление сообщений, персональную
очистку истории и завершение сессии.

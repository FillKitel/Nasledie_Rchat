# Nasledie RChat

Новая кроссплатформенная версия мессенджера команды. Рабочее название интерфейса
пока — «Маяк»; бренд можно заменить без переделки архитектуры.

Сейчас в репозитории есть устанавливаемый web-прототип (PWA), который адаптируется
под desktop, macOS, iPhone и Android. Параллельно создаётся Flutter-клиент для
настоящих приложений iOS, Android и macOS.

## Быстрый запуск

```sh
python3 -m http.server 4173 --directory app
```

После этого откройте `http://127.0.0.1:4173`.

## Что уже работает

- адаптивный интерфейс для большого и маленького экрана;
- список и поиск диалогов;
- переключение между чатами;
- отправка сообщений с локальным сохранением;
- быстрые реакции и имитация ответа собеседника;
- светлая и тёмная темы;
- PWA-манифест и offline-кэш приложения.

## Структура

- `app/` — запускаемый клиентский прототип;
- `clients/rchat_app/` — единый Flutter-клиент (добавляется);
- `docs/ARCHITECTURE.md` — план перехода к полноценному продукту;
- `docs/LEGACY_AUDIT.md` — что наследуем из старого RChat;
- `outputs/` — пользовательские сборки и демонстрационные материалы.

# Nasledie RChat

Новая кроссплатформенная версия мессенджера команды. Рабочее название интерфейса
пока — «Маяк»; бренд можно заменить без переделки архитектуры.

Сейчас в репозитории есть web-прототип (PWA), который адаптируется под desktop,
macOS, iPhone и Android, плюс первый локальный realtime-сервер для живой проверки
сообщений между двумя окнами. Параллельно создаётся Flutter-клиент для настоящих
приложений iOS, Android и macOS.

## Быстрый запуск

```sh
./script/run_local_chat.sh
```

После этого откройте `http://127.0.0.1:4173`. В интерфейсе появится карточка
«Подключить телефон» с QR-кодом и LAN-ссылкой вида `http://192.168.x.x:4173`.
Если открыть эту ссылку на iPhone или Android в той же Wi‑Fi сети, диалог
«Живой чат» будет получать сообщения через локальный сервер.

На iPhone можно открыть ссылку в Safari, нажать «Поделиться» → «На экран Домой»
и получить PWA-иконку «Маяк» без App Store/TestFlight.

Статический режим без сервера всё ещё можно открыть так:

```sh
python3 -m http.server 4173 --directory app
```

Но в нём «Живой чат» останется без realtime-доставки.

## Что уже работает

- адаптивный интерфейс для большого и маленького экрана;
- список и поиск диалогов;
- переключение между чатами;
- отправка сообщений с локальным сохранением;
- быстрые реакции и имитация ответа собеседника;
- светлая и тёмная темы;
- PWA-манифест и offline-кэш приложения.
- локальный realtime-сервер;
- живой диалог между двумя клиентами через HTTP + Server-Sent Events.
- QR-подключение телефона к локальному серверу.

## Структура

- `app/` — запускаемый клиентский прототип;
- `server/` — локальный realtime-сервер для v0.3;
- `clients/rchat_app/` — единый Flutter-клиент (добавляется);
- `docs/ARCHITECTURE.md` — план перехода к полноценному продукту;
- `docs/LEGACY_AUDIT.md` — что наследуем из старого RChat;
- `outputs/` — пользовательские сборки и демонстрационные материалы.
